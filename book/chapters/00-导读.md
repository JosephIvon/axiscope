# 导读：怎么读这本书

> **本卷定位**：axiscope 是**一个真实的开源项目**（离线伺服/过程波形诊断与归因引擎）。
> 这本书不是它的宣传册，也不是它的使用手册——
> 它是**对这个项目的工程解剖**：把它的设计决定、纪律、以及它欠的账，一章一章摊开，
> 并且**每一处事实都带着可机器复核的坐标**。

**锚点**：`axiscope@7f7c37e`（坐标 = 文件 + 行号，代码按锚点读源文件）

---

## 写给读者的建议

**如果你只读三段**：

1. 第 1 章 §1.4「三档退出码」——一个工具对外的全部语言；
2. 第 3 章 §3.5「看不见 ≠ 没有」——本仓最重要的一条纪律；
3. 第 9 章 §9.3「账面 vs 实测」——两个数字之间的差，有时是事实，有时是口径。

**如果你要动手**：每章末尾都有「动手」与「习题」两节。
动手环节都是**可在本仓跑通的**，习题都要求你**引用具体坐标作答**。

**如果你在评估这个项目**：先读第 9 章（它先说自己的短处），
再读第 7 章 §7.5（`top1_hit = 0` 的完整读法）。

**如果你在读一本书而不是在读一个项目**：那请注意一件事——
本卷的坐标是**真坐标**，不是修辞。
`book/tools/audit_coords.py` 会把每一处 `文件:行号` 解析回源文件、
打印被引行的原文，并核对那一行**是否真的在说那句话**。
这意味着：**你可以在任何时候复核本书的每一个事实性断言**。

## 坐标是怎么用的

本书里每一处事实都长这样：

```
`docs/kb/KB3-tuning-rules.md:26-29`
```

含义是：斯图加特大学那批数据集的文件，
在**锚点 commit `7f7c37e`** 的 `docs/kb/KB0-conventions.md` 的**第 26 到 29 行**。

**为什么用行号**：本仓的 Wiki 一开始是**故意不用行号**的
（`docs/wiki/01-overview.md:3-4`：行号会随增行漂移）。
但那是在**没有锚点**的前提下。
本书引入了锚点——**行号在锚点处被冻结**，于是它同时有两个优点：
精确，且可复核。

**怎么复核**（三步）：

```powershell
cd /d/workspace/axiscope
python book/tools/audit_coords.py      # 解析全部坐标，打印被引行原文
python book/tools/locate.py "看不见"    # 反查：这句话在哪一行
```

第一条命令会告诉你哪些坐标**指错了行**；
第二条让你能**从一句话反查它的行号**——
它也是本书的写作工具（写的时候，先用 `locate.py` 找到行号，再落笔）。

## 证据与坐标

本卷所有事实性断言的坐标，集中在两处：

1. **每章末尾的「## 证据与坐标」表**——该章引用的全部坐标 + 用途；
2. **每章末尾的「本章事实性句子坐标」**——该章**逐条**列出的坐标集合，
   供 `audit_coords.py` 逐条解析。

**本卷的坐标审计结果**（本机实跑，见 `book/ASSETS.md`）：

| 项 | 值 |
|---|---|
| 引用总数 | 见 `book/ASSETS.md` 当场实测 |
| 可解析 | 同上 |
| 失败 | **必须为 0** |
| 行锚断言 | 见 `book/checks.json` |

**仓外原件**：本卷引用的决策清单原件归在书仓（那个仓**没有对外发布**），
但**同一份内容现在公开可读**——`forensics-mcopilot` 仓里有一份归档，
sha256 与本卷副本逐字节一致（见 `book/evidence/REGISTRY.json`）。
即便如此，本卷仍然 vendor 一份进 `book/evidence/`，理由换成了**坐标要自足**：
读者只 clone 本仓就能核到每一个坐标，不必再 clone 第二个仓、也不必指望它一直在。
登记**指针 + size + sha256**。
**没有登记的"仓外文件"一律判失败**——
否则拼错一个文件名也能过关，门禁就成了只会说"通过"的摆设。

## 三条阅读纪律

1. **坐标是坐标，引用是引用。** 本书引用的每一句原文都可以回查；
   但本书**自己的判断**（比如"这条纪律是全章最重要的"）不是坐标，
   它是**我的判断**。本书尽量把这两种东西分开排版。
2. **数字先问口径。** 第 9 章会用一个真实例子说明：
   两个都"对"的数字，差 781 行——差的是**计数口径**。
3. **"没做"比"做了"更值得看。** 第 7 章的 `top1_hit = 0`、
   第 9 章的 7 笔账，都是这个项目**最诚实**的部分。
