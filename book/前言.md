# 前言：为什么要把这本书写出来

> **本卷主张**：一个工程项目的价值，不在它宣称自己做了什么，
> 而在**它能不能被第三方逐条复核**。
> axiscope 把这件事做到了一个少见的程度——
> 它的契约、知识库、裁决台账、探针与门禁，全都在仓内，
> 每一个数字都挂着**可重跑的产物**。
> 这本书的任务只有一个：**把这套东西拆开给人看，并且让书里的每一句话也接受同样的复核**。

---

## 一、这本书不是什么

它**不是**：

- axiscope 的使用手册——没有"如何安装、如何调用"的操作序列；
- axiscope 的技术规格书——规格书在 `docs/contracts/` 里，那七份契约写得比本书细；
- axiscope 的宣传材料——本书第 7 章会告诉你它当前的 Top-1 命中是 **0**，
  以及那为什么**不是**一件可耻的事；
- 一本"AI 时代的伺服诊断"之类的行业读物——本书讲的全部是这一个仓里的具体决定。

它**是**：

- 一份**工程解剖**：把"为什么这样定"连同"这个决定的代价是什么"一起摊开；
- 一份**可复核的读本**：书里的坐标是机器可解析的，`audit_coords.py` 会逐条打印被引行原文，
  并核对"那一行是不是真的在说那句话"；
- 一份**关于纪律的案例集**：这本书真正的主题不是伺服诊断，
  是**怎样让一个项目在没有真机、没有完整数据的情况下仍然不说假话**。

## 二、这本书为什么用坐标

大多数技术书引用代码时写"见 `features.py` 中的某处"。
那种引用**不可复核**：读者得自己找，找到哪一处算对的，全凭眼缘。

本仓自己的 Wiki 走的是另一条路——**明确不用行号**
（`docs/wiki/01-overview.md:3-4`：行号会随增行漂移，KB0 A-117 口径）。
那条纪律在**没有锚点**的前提下是对的：行号会漂，所以不该引用行号。

但本仓同时有**另一个**事实：项目在 2026-10-22 收了尾、进了停机点
（`docs/项目回顾与收尾_20261022.md:65-69`），
主线契约/知识库/引擎/测试全部入库，**不在停机点上叠加**。

**停机点 + 锚点 = 行号被冻结**。
于是行号同时拿到了两个优点：精确（能指到某一句），
且可复核（锚点处的内容永远不变）。

本卷的锚点是 `axiscope@3576c9c`，由 `book/tools/_anchor.py` **单点定义**；
`check_book_structure.py` 会扫描全书，核对每一处 `axiscope@<hash>`
字符串与那一个定义**逐字一致**。

**为什么强调"单点定义"**：如果锚点字符串在书里和工具里各写一份，
它们迟早会漂。漂了之后，坐标审计照样全绿——
那正是"0 失败"变成假话的形状。

## 三、本卷怎么写自己

本书第 9 章有一条专门讲这个：在自己的项目里，
`src/agent` 目录**在两个提交下都不存在**，
而收尾文档的账面栏写了"`src/axiscope` + `src/agent`"。

**本卷不改那份历史文档**——按该仓"原文在案"的纪律
（`docs/项目回顾与收尾_20261022.md:47`），
历史事实就是历史事实。
本卷在第 9 章 §9.3.1 **把它记明**，并说明它与"实测"之间的差是**口径**还是**事实**。

**这是本书对待自己的态度**：不修改被引用的历史，
不掩盖历史里的不一致，
而是**把不一致摆出来、说清它是什么**。

## 四、读这本书需要什么

- 会读 Python 与 Markdown（不需要会写）；
- 最好有一个终端，能 `git clone` 本仓并跑 `book/tools/` 下的门；
- **不需要**伺服、产线、真机、示波器，也不需要任何付费数据。

**如果你只想读观点**：每章开头的「可验证主张」块是浓缩版，
每章末尾的「讲师 90 分钟」表是讲稿提纲。

**如果你想复核**：

```powershell
git clone https://github.com/<owner>/axiscope
cd axiscope
python book/tools/audit_coords.py       # 坐标逐条解析
python book/tools/check_book_structure.py # 结构体检
python book/tools/verify_crops_verbatim.py # 裁剪版逐字核对
```

## 五、一句题词

> 录下来的波形就是闭环反馈的完整记录。
> ——`docs/DECISION-2026-10-19-方向裁决.md:21`

这句话是 axiscope 全部工作的**合法性根基**（第 1 章 §1.2 整章讲它）。
它同时也是这本书的写作原则：

**你录下来的东西，就是你手上的全部证据。
别去补，别去猜，别去修饰——
把它按原样摆出来，让别人自己看。**
