# C5 — 评测协议（防自我验证）

## 0. 要解决的问题

本项目最大的可信度风险不是算法不够好，而是**循环论证**：
自己写一个二惯量仿真器造波形 → 用自己提炼的规则诊断 → 再用同一个仿真器验证建议有效 → 自己打分。
四份草案里最强的那一份（EquipPilot）批评了"数据集是自己编的、答案是自己编的、最后让大模型打分"，
**这条批评首先命中的是我们自己的方案**，不是它自己提的方案。本文件是应对。

> **本节是 A-88 的一个实例，不是全部**。A-88（KB0 §7.3）把"同源无证明力"一般化：
> 凡由某个知识库/契约/代码派生的核对物（评测用的期望值、核对清单、自检用例、快照、评审意见），
> 对**它自己那个来源**的证明力记 0——不限于"仿真器验证仿真器"这一种形态。
> 因此本文件 §2/§3 的每条指标还须满足：**期望值的来源与被打分的实现不得同源**，
> 同源时该指标只能报告"内部一致"，不得并入任何对外能力主张（措辞口径见 KB0 §6 检查 20、KB3 §0 纪律 16）。
> 典型反例（第三方实现审计中的同类缺陷，非本项目）：生成的 SDK 签名凭记忆写错，
> 而随包的核对清单由同一份生成器知识库派生 ⟹ 清单只索引"去哪里核对"，发现不了"生成错了"，
> "清单全过"于是被误读成"核对完成"。

## 1. 证据分层（核心机制）

每个评测案例标注 `source_tier`（**字段权威名 = KB0 §4，已裁 A-54**；旧名 `evidence_tier` 在本文件就地作废，
中文叙述里说"证据层级"是表述不是字段名），**指标必须按层分别报告，禁止合并成一个总数**。
本表五档值域（`T1-a`/`T1-b`/`T1-c`/`T2`/`T3`）与 KB0 §4 逐行一致，不另造档位。

| tier | 来源 | 真值由谁决定 | 能证明什么 | 不能证明什么 |
|---|---|---|---|---|
| **T1-a 真实测量** | **DaRUS（斯图加特大学，CC BY 4.0，已下载核验，见 `KB7-dataset-da-rus-cat.md`）**：绳索驱动试验台 + 直驱试验台，TwinCAT Scope View 原生导出，32/40 通道，含控制器参数与三套独立位置测量 | 独立研究者的实验设计（目录名即元数据真值） | 解析器正确性、触发门控、方向符号、恒速纹波、摩擦/stiction/爬行、前馈失配（kff=1.5）、传感器交叉验证、滑移、热相关漂移（**仅相关性，非归因真值**，见 §9） | **kHz 级共振（fs=1kHz，奈奎斯特 500Hz ⟹ `reliable_band_hz=400`，结构性真空见 §9，已裁 A-65）**；故障归因（受试对象健康，非故障数据）；半导体设备外推 |
| **T1-b 外部故障真值** | 凯斯西储 CWRU 轴承、帕德博恩 CM 电机三相电流、Aalto 齿轮、MFPT | 独立研究者，有论文与实验台背书 | 频谱特征提取、模态识别、机械 ↔ 电气**二分类**能力（已裁 A-63：**只计二分类命中率，禁止映射到具体 slug**，见 §3） | 位置环/跟随误差/整定建议能力（无位置通道）；22-slug 级 Top-1/Top-3 分母（硬映射会让分母静默错位，A-63/A-19） |
| **T1-c 自采真实测量（有条件）** | 本项目**自行执行**的标定/几何实验：自建网格工装 + 真实相机 + 真实轴 + 自记温度序列（KB0 §7 A-24） | 实验设计由自己做，但**测量是真实物理量**，不是仿真 | 标定残差场形态、方向性分量、温漂相关性 | **不是产线数据**；不得与 T1-a/T1-b 混算能力指标；**若拿不到工装就整层作废**，标定模块必须如实声明只有 T2+T3 |
| **T2 文献** | 合成波形，但**规则阈值与故障模型参数全部取自公开文献与厂商手册**，不取自本项目仿真器默认值 | 文献 | 判据实现与文献一致、可复算 | 现场有效性 |
| **T3 合成** | 本项目二惯量+摩擦模型，带 `truth.json` | 我们自己 | 端到端流程跑通、回归不退化、覆盖率 | **任何"诊断准确"的主张** |

> T1 拆为 a/b/c 三支的原因：DaRUS 提供真实 TwinCAT 波形但无故障；CWRU/帕德博恩提供故障真值但无位置通道，
> 且只进二分类不进 slug 分母（A-63）；T1-c 是 A-24 的**有条件层**——自采真实测量但**不是产线**。
> 三支互补，且**都不得外推为"半导体设备现场验证"**。

硬规则：
- 对外报告的"根因 Top-3 命中率"等能力性指标，**只能来自 T1+T2**（slug 级实为 T1-a+T2，见 §3 与 A-63）。
- T3 指标只允许出现在"流程正确性"章节，标题必须写明"合成集，不用于能力主张"。
- **T1-c 禁止与 T1-a/T1-b 混算任何能力指标**（分母分开、分层报告，已裁 A-24/A-54）；
  该层未取得（拿不到自建工装）时**整层撤回**，标定模块必须如实声明只有 T2+T3。
- 报告首页放一张"证据层级声明表"，列出每个数字来自哪一层。这是作品集里最能打的一页。

## 3. 指标

| 指标 | 定义 | 首轮目标 | 备注 |
|---|---|---|---|
| Top-1 / Top-3 根因命中率 | 仅 **T1-a + T2** 的 slug 级案例；**T1-b 不进本指标分母**（已裁 A-63） | ≥45% / ≥75% | 附人工基线（见 §5）。分母若混入 T1-b，数字一律作废——轴承点蚀的真值不是 `mechanical_backlash`，硬映射会让分母静默错位（A-19 精神） |
| 机械 ↔ 电气二分类命中率 | 仅 T1-b（CWRU/Paderborn/Aalto/MFPT），期望类别取 `family` 级（非 slug 级，已裁 A-63） | 不设通过线，报数值 + 案例数 | T1-b 的对外角色是"本族判据的通用故障检测力有外部数据支撑"，**不是**"22 个 slug 都有外部真值"；单独设行就是为了没人能把两类指标偷偷相加 |
| **拒答正确率** | 在 `none_of_the_above` 案例上正确输出 `insufficient_data` 的比例 | ≥80% | 比命中率更能说明可靠性；§9 结构性真空能力项的拒答案例也计入本行 |
| 证据准确率 | 抽样人工核查：每条 `supporting_evidence` 的特征路径存在且数值与 C2 一致 | 100% | 结构性保证（见下） |
| **无依据成功声明** | `expected_effect` 标 `simulation_validated` 但无对应 V* 记录，或 V* 的 `fit_residual_pct`>25% 却未降级 | **0 次** | 硬门禁，出现一次即视为失败 |
| **禁语违例** | 报告文本命中该案例 `forbidden_conclusions[]` 或 KB5 §6.3 禁止措辞表的次数（含"未发现异常/未发现谐振"类越级措辞，见 §9） | **0 次** | 已裁 A-59：C3 硬性规则 14 的评测侧对偶。命中率判"说对没有"，禁语表判"有没有说过分的话"；A-31 的自动检查正是靠这张表落地 |
| 置信度校准误差 ECE | 预测置信度 vs 实际命中的分桶偏差 | ≤0.10 | **本项目最重要的单一指标** |
| 反事实区分度 `CF_Discrimination` | 归因前反事实自检（KB4 §4）在**命中案例**与**错判案例**上的通过率差 | 差值 ≥0.20 | 差值小 ⟹ 反事实检查没有区分力，是设计缺陷而非"数据都好"。与 KB4 §4.3 的 `CF_Tier_Divergence`（T3 与 T1+T2 的分层背离）**是两个不同的量**，不得混用（A-47） |
| 建议有效性 | 隐藏测试集上，被推荐参数在 T2 案例上的实际改进 vs 报告声称改进 | 偏差 ≤30% | |
| 可追溯率 | 有完整 C2 特征快照 + 规则触发记录 + 模型配置的运行占比 | 100% | |
| **案例执行分列** | 每族报告 `执行 N / 跳过 M`，凡标注"需真机 / 需厂商手册原文 / 需现场接线表 / `skipped` / `pending`"的案例**单独成列，不进通过数**（A-87） | 分列呈现率 100%，禁止合并汇总 | 载体是 KB8 §6 的配额表与 §执行统计。触发事实：第三方实现把唯一能抓适配器方向写反的那条（需真机）并进了"74 项测试全绿"。**指标本身不新增证据，只是让缺证据落在哪一格可见** |
| **外部核对计数** `external_counts` | `audit.external_counts = {verified k, total n}`，只有 `verified_by = self` 且工件存证在本仓库内才计 `k`（C3 规则 17、A-88/A-89） | 不设通过线，**报 `k/n` 原值** | `k = 0` 时相关叙述封顶"样板就绪，签名与位号未经外部核对"。这一行故意不设目标值：设了就会有人为了达标把手册读别人的动作记成自己核过的 |
| **断言负向测试覆盖率** | 声称能自曝某类缺陷的断言/检查器中，附了"故意注入该缺陷、断言真的触发"用例的比例（KB0 §6 检查 22） | 100%，缺用例的断言降格为**约定**而非门禁 | 来源是 GLM 同轮的真实负向测试（`GEN FAIL: ACS 未入套件但矩阵无排除声明`）。"断言在跑"≠"断言能抓"，与 §0 的 A-88 是同一问题的两侧：前者管证据资格，本行管**检查器的证据资格** |

**证据准确率的结构性保证**：规则引擎只能引用 C2 特征路径，不允许自带数值。
加载期校验每条证据的 `feature` 能在 C2 JSON 中解析到、且 `value` 与之一致，
不一致直接抛异常。因此该指标不是"努力达标"，而是"结构上无法造假"——这一点要在报告里明说。

**为什么 ECE 是核心指标**：工业诊断 agent 的价值不在"猜对"，在"知道自己不知道"。
一个置信度 0.4 的猜测和一个 0.9 的判定如果长得一样，工程师不敢用。
校准曲线图应作为作品集的头图。

## 4. 消融实验

| 组 | 配置 | 检验的假设 |
|---|---|---|
| A | 纯 LLM：把降采样波形转成文字/表格喂进去，直接要诊断 | 基线 |
| B | A + 确定性特征内核（C2） | 信号处理内核是否必要 |
| C | B + 规则库（C3）+ 验证门控（C4） | 验证门控是否减少无依据主张 |
| D | C + 有界 ReAct（用 `next_data_to_collect` 主动要数据，最多 2 轮） | 自主循环是否值得其成本 |

预期 B≫A（若不然，说明特征内核是花架子，应删）。
D 只在"缺通道"类案例上应优于 C；若整体提升 <5 个百分点，**按 EquipPilot 草案的原则砍掉自主循环**。
每组报告：命中率、拒答正确率、ECE、平均 token 成本、平均耗时。

## 5. 人工基线（必须做，否则数字无意义）

- 请 ≥2 位做过伺服调试的工程师，在**不看 agent 输出**的条件下，对同一批 slug 级案例
  （**T1-a + T2**，含波形图；T1-b 只给 family 级期望、不参与人标排序，已裁 A-63）
  给出根因排序与置信度。记录他们的耗时。
- 报告形式：`agent vs 工程师` 的命中率差、ECE 差、单位案例耗时比。
- 找不到 2 位工程师时的降级方案：只报 agent 自身指标 + 明确写"无人工基线，绝对数值不可横向比较"。
  **不允许**用文献里的他人系统数字当基线（任务定义不同）。

## 6. 失败案例公开

- `bench/failures/` 保留全部失败案例：输入、C2 特征、触发规则、输出、真值、错在哪一层的分析。
- 混淆矩阵：哪种故障被误判成哪种。预期最高频混淆对是
  `mechanical_resonance ↔ electrical_feedforward_mismatch`（两者都在加减速时刻出现纹波；
  KB0 §2 权威 slug 带 `electrical_` 前缀，旧稿漏写已补，禁显示名/半截名，A-19）。
  把这个混淆对的判别条件单独强化，并作为技术叙事的高潮点。
- 禁止只放成功演示视频。

## 8. 备选方向（若 §7 触发）

**运动控制卡跨厂商能力差异矩阵 + 换卡影响分析 agent**。
理由：数据 100% 可得（固高/雷赛/正运动 SDK 文档与头文件公开），零硬件依赖，
且调研已确认差异化空间收窄但存在——核心卖点必须是**"不可映射项"清单**
（坐标系模型差异、回零编码不兼容、LANE/CAM/位置比较锁存等各家独有能力），
而不是"又一个 RAG + 代码骨架生成器"。
风险：算法深度弱于伺服诊断，对"AI 算法工程师"定位的信号不如主方向准。

## 9. 结构性真空与拒答纪律（已裁 A-64 / A-65）

> 落点说明：KB0 §7.3 把这两条的落点写作 "C5 §4"；但 C5 §4–§8 的编号已被 KB2 §4.9、KB4（CAP/D 表）、
> KB5、KB6、KB8 §6 与 `DECISION-2026-10-19-方向裁决.md` 按号引用，**禁止整体平移**，故本小节落在文件末尾的 §9。

**结构性真空** = 某能力项在 T1/T2/T3 三个来源上都拿不到可对外主张的合法正例——不是"还没做"，
而是"当前没有正例来源"。裁它为真空后写入拒答纪律，**禁止为凑覆盖率造案例、禁止把外部数据硬映射成 slug**。

| 能力项 | 为什么是真空 | 唯一合法的对外形态 | 禁止形态 |
|---|---|---|---|
| `mechanical_thermal_drift`、`electrical_motor_heating`（A-64） | 三条通路全堵：T3 被 KB5 §6.1 禁用于能力主张；T1-a 只给热相关漂移**而无归因真值**；T2 需 ≥30 min 冷→热机的 `temp`+`fe` 同采，手头没有 | 只以 **T2 文献合法性**出现在叙事里（"该判据阈值有文献依据，本数据集无法检验"） | 不得出现在任何能力声明（in-capability 清单 / 报告首页能力表 / 简历式条目）里；只能进 `not_evaluable` 与拒答表 |
| kHz 量级判据：R-03/R-04 机械谐振·双惯量配对，及电流环带宽/换刀频率类（A-65） | **T1-a 是 fs=1 kHz ⟹ Nyquist 500 Hz ⟹ `reliable_band_hz = 400 Hz`**（C2 规则 7），而 KB0 §1 要求这两条判据 `reliable_band ≥ 2000 Hz`——**数据层面不可达**，不是阈值松紧问题；T1-b 无位置通道且不映射 slug（A-63） | 报告侧 `unavailable` + `freq_limits.blocked_rules=["R-03","R-04"]`（C2 频段门禁）；对外只讲 T2 文献合法性 | **禁止**输出"未发现异常 / 未发现谐振 / 无共振风险"——"看不见"和"查过没问题"是两回事（C2 规则 7 同款纪律） |

纪律（逐条可机检）：
1. 真空能力项的合法输出 = `differential.not_evaluable[]` 登记 + 拒答；这些案例计入 §3 的**拒答正确率**分母，
   **不计入**任何命中率分母。
2. "未发现异常"类措辞在 `blocked_rules` 非空的案例上出现 ⟹ 命中 §3 **禁语违例**行（0 次硬门禁），
   禁语来源：KB5 §5.4 `c5_case.forbidden_conclusions` + KB5 §6.3 禁止措辞表（已裁 A-59）。
3. 要补的是**数据**不是代码：这两项登记在 KB8 §2.3 长期缺口 G-4/G-5，属 KB0 A-64 明文的
   "长期缺口而不是实现期能修的债"；§7 的止损判据不得把它们算进"做深做透"的收缩目标——
   收缩目标若写"只做共振识别"，指的多半只能是 <400 Hz 低频模态（DaRUS 频段内，KB8 §6 能力配额），
   而非 kHz 档的 R-03/R-04。
4. **为什么承认真空比造案例强**：§0 的循环论证最擅长的就是"把覆盖矩阵的空格用东西填上"。
   空格只是少一分，造案例是把整页数字的可信度押进去——而且违反 A-31/C3 规则 14 的措辞纪律，
   一旦被外部审计读到"未发现谐振"出现在 400 Hz 数据上，前面所有诚实分层全部作废。
