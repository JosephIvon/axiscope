## 一、这是什么

axiscope：离线伺服波形诊断与归因引擎。输入已录制波形，输出可解释根因归因 +
参数建议 + 仿真验证 + 现场操作步骤（`field_procedure`，人执行），**不含任何
自动写入真机**（C3 `safety.writes_to_device=false`、`requires_human_approval=true`）。

合法性根基是一条真值裁决（`docs/DECISION-2026-10-19-方向裁决.md` §2）：
**录下来的波形就是闭环反馈的完整记录**——"伺服整定 AI 碰不了"的断言混淆了
在线闭环自整定（确实不能碰，安全与责任问题）与离线诊断（纯数据分析，厂商
自己都在做：SigmaWin+ / PANATERM / MR Configurator2 / InoServPad / TE5960）。
